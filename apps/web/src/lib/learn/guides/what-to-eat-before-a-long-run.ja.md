## 走る前の補給がなぜ大切か

短くてゆるい走りに特別な準備はいりません — 空腹のまま玄関を出ても問題ありません。ロング走は別です。一時間以上外に出るようになると、前に何を食べたかが、力強く走り切れるか、途中で失速してハンガーノックになるかを決めます。だいたい合わせるのは難しくなく、そして劇的な違いを生みます。

## タイミング

最も大きなレバーは、何を食べるかよりも、*いつ*食べるかです。

- **しっかりした食事**は、走る前に二〜三時間の消化時間を必要とします。食べたら、胃を落ち着かせましょう。
- **軽い間食**は、しっかりした食事を入れられないとき、30〜60分前なら大丈夫です。
- **走る直前**が最悪の窓です — 消化されずに胃に居座る食べ物が、あの忌まわしい走行中の脇腹の痛みや胃の不調を招きます。

自分に合うタイミングは練習で見つけましょう。決してレース当日に試してはいけません。

## 何を食べるか

**炭水化物中心・低脂質・低食物繊維・適度なたんぱく質**を目指しましょう。炭水化物は筋肉が最初に手を伸ばす燃料で、消化もきれいです。ロング走前のよい選択肢 — オートミール、はちみつかジャムを塗ったトースト、バナナ、ベーグル、ごはん。胃にもたれずに、すぐ使えるエネルギーをくれます。

およそ90分を超える走りでは、走行*中*にも炭水化物をとる計画を立てましょう — ジェル、グミ、スポーツドリンクを30〜45分ごとにとれば、タンクが空になるのを防げます。

## 水分補給

前の数時間は喉の渇きに応じて飲みましょう — スタート時にしっかり水分が足りていることが目標で、スタートラインで溺れることではありません。多くの人にとって、走る前の食事と一緒にコップ一杯か二杯の水で十分です。暑い日や非常に長い努力では、水分を携帯し、一度に大量に飲むのではなく、こまめにすすりましょう。

## 避けるべきもの

- **高脂質・高食物繊維の食べ物**（揚げ物、クリーム系のソース、大盛りのサラダ、豆類） — 消化が遅く、胃の不調を引き起こします。
- **目新しいものすべて。** レースの朝は、慣れないジェルや朝食を試すときではありません。補給は練習のロング走でリハーサルしましょう。
- **多すぎ、遅すぎ。** 走る一時間前の重い食事は胃に居座り、あなたを失速させます。

これを詰めるのは、いくつかの実験の問題です。何を食べ、走りがどう感じたかを記録すれば、パターンはすぐにはっきりします — どんな朝食とタイミングが、自分を軽く、満タンに感じさせてくれるかを、あなたはすぐに学ぶでしょう。
