## トレイルランニングは、同じ靴で行う別のスポーツ

ロードランニングがリズムとペースの競技だとすれば、トレイルランニングは適応の競技です。地面は不整で、勾配は急で、ペースを決めるのは脚ではなく地形です。ロードランナーはいつものスプリットを期待してやって来て、はるかに遅いことに面食らうことがよくあります — それは正常で、正しいのです。トレイルでは、**ペースではなく努力こそが、意味を持つ指標です。**

## 地形を読む

- **足元ではなく、前を見る。** 足を見つめるのではなく、数メートル前の地面を見渡してラインを選びましょう。
- **荒れた、あるいはテクニカルな地面では歩幅を縮める。** 速く軽いステップは、ロードの長いストライドならつまずくところでもバランスを保ってくれます。
- **急な上りは歩く。** トップのトレイルランナーでさえ、最も急な区間は歩きます — 上りのパワーハイクは効率的であり、失敗ではありません。走るのは、歩くより速い場所のためにとっておきましょう。
- **リラックスして下る。** 重力に助けてもらい、膝を柔らかく保ち、斜面と戦わないこと。転倒を招くのは力みです。

## ロードと違う装備

- **トレイルシューズ** は、ゆるい・濡れた・泥の地面でグリップするためのアグレッシブなラグ（突起）を備えています。ロードシューズは滑り、トレイルシューズは噛みます。
- **短い周回より長いものには、水と補給食を携帯する** — 山には店も水場もありません。
- **スマートフォンと一枚の上着。** 道を外れると天気の変化は速く、助けから遠く離れていることもあります。軽い防水ジャケットは小さくたためて、一日を救ってくれます。

## 道を外れても安全でいる

トレイルの自由には、公園を一周するより大きな責任が伴います。

- **誰かに、ルートと帰る予定の時刻を伝える** — とくに一人で走るときは。
- **どこへ向かうかを把握する。** 時計かスマートフォンに地図かGPSルートを携えましょう — どこもかしこも木に見えるとき、分岐を誤るのは簡単です。
- **コンディションを尊重する。** 泥、氷、渡渉、薄れゆく光は、どれも危険を高めます。楽しくなくなり、危なくなり始めたら引き返しましょう。

始めるのに最適なのは、近くのよく整備された人気のトレイルです。ほかの人が走ったルートを眺め、近くの小道を探って、最初のやさしいオフロードの周回を見つけましょう — そして足さばきと自信が育つにつれて、少しずつ伸ばしていきましょう。
